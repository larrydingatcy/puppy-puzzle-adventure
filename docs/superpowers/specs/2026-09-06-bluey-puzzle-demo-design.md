# Bluey 5×5 拼图试玩版设计

## 目标

制作一款无需登录、可直接在现代手机和桌面浏览器中游玩的最小拼图试玩版。玩家通过交换 25 块图片碎片还原一张 Bluey 图片，完成后得到清晰的庆祝反馈。

## 范围

首版只包含一个固定关卡和固定 5×5 难度，不包含账号、后端、存档、排行榜、关卡选择、音效或联网功能。

## 图片与版权

- 使用 Bluey 官方壁纸页面中的横向宣传图作为临时试玩素材。
- 图片作为本地静态资源保存，游戏逻辑只引用一个集中配置的图片路径，便于后续替换成用户拥有授权的素材。
- 页面底部注明本项目仅用于非商业试玩；Bluey 及相关角色版权和商标归 Ludo Studio、BBC Studios 等权利方所有。
- 正式发布或商业使用前必须取得适当授权或替换素材。

## 技术方案

采用无构建步骤的原生 HTML、CSS 和 JavaScript。项目可由任意静态文件服务器运行，不依赖框架、数据库或第三方服务。

游戏状态与 DOM 渲染分离：纯 JavaScript 模块负责生成顺序、打乱、交换和完成判断；页面模块负责用户输入、计时、步数显示、动画和可访问性提示。

## 用户流程

1. 页面载入后展示标题、简短玩法说明、原图缩略图和“开始拼图”按钮。
2. 玩家点击开始后，系统生成可验证为非完成状态的 5×5 随机排列，同时开始计时。
3. 玩家先点击一个碎片，再点击另一个碎片，两块位置互换；第一次选择有明显描边。
4. 每次有效交换计为一步，并立即检查是否完成。
5. 完成后停止计时，显示步数、用时和轻量庆祝动画。
6. 玩家可点击“再玩一次”重新打乱并开始新一局。

## 界面与交互

- 单页居中布局，使用明亮的蓝色、浅黄色和圆角卡片，整体轻松活泼，但不复制官方站点样式。
- 拼图保持 16:9 比例；25 个按钮组成 5 列网格，每块使用同一张图片的不同背景位置。
- 桌面端和触屏端都采用点击两块交换，避免依赖拖放 API。
- 拼图按钮有键盘焦点、选中状态和位置说明；状态变化通过可访问性状态区域播报。
- 小屏幕上缩减间距和字号，拼图宽度不超过视口。

## 状态与边界情况

- 初始状态尚未计时，步数为零。
- 打乱算法不得返回已完成顺序；若随机结果恰好完成，则重新打乱。
- 重复点击同一块会取消选择，不增加步数。
- 完成后锁定拼图交换，直到玩家点击“再玩一次”。
- 图片加载失败时显示明确提示，并保留重新加载页面的建议。

## 测试与验证

- 使用 Node 内置测试运行器测试纯游戏逻辑，无需额外测试依赖。
- 自动化测试覆盖：生成 25 块、打乱后非完成、交换两块、重复选择不计步、完成判断。
- 在本地静态服务器中手动验证桌面和窄屏布局、鼠标与键盘交互、计时、完成弹层和图片加载。
- 最终运行完整测试，并检查页面脚本无控制台错误。

## 文件规划

- `index.html`：页面结构和可访问性文本。
- `styles.css`：响应式视觉样式和庆祝动画。
- `src/puzzle.js`：可测试的纯游戏逻辑。
- `src/app.js`：页面渲染和交互控制。
- `tests/puzzle.test.js`：游戏逻辑测试。
- `assets/bluey-puzzle.png`：临时官方宣传图。
- `README.md`：运行方式、玩法和版权说明。

## 完成标准

- 用户无需登录即可开始游戏。
- 5×5 拼图可通过点击任意两块交换并最终完成。
- 步数和用时准确更新，完成后出现庆祝反馈。
- 手机和桌面浏览器均可操作。
- 自动化测试全部通过，静态页面可由本地服务器正常加载。
